# ATSMiniProject

Thu muc code chinh cho website ASP.NET MVC 5 cua du an ATS Mini.

## Quy uoc nhanh

- `Views/Shared/_Layout.cshtml`: layout public cho ung vien.
- `Views/Shared/_AdminLayout.cshtml`: layout quan tri cho Admin/HR.
- `Models/ATSMiniDB.edmx`: Entity Framework 6 Database First sau khi ket noi SQL Server.
- `Uploads/CVs/`: luu file CV upload; database chi luu duong dan tuong doi.
- `ViewModels/`: chua model rieng cho form va validation.
